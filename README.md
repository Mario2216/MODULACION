# PROJENER: Marco Adaptativo de Guerra Electrónica y Ciberseguridad en Aviónica Autónoma

Repositorio oficial de la implementación experimental para el Trabajo Fin de Máster (TFM) en Inteligencia Artificial (UAX).

## 📋 Descripción del Proyecto
PROJENER aborda la integración de técnicas avanzadas de aprendizaje automático y profundo para la clasificación de señales de radiofrecuencia (RadioML), detección de anomalías y toma de decisiones autónomas en entornos de aviónica y guerra electrónica (EW). El sistema integra modelos basados en arquitecturas CNN-Transformer, Aprendizaje por Refuerzo Profundo (PPO) y aumentación de datos mediante Redes Generativas Antagónicas Condicionales (WGAN-GP).
